# Cyber Security Projects

Beginner-level cyber security projects built while learning Python and web basics.

## Projects

### 1. Password Strength Checker (Python)
**File:** `check.py`

Checks how strong a password is.

**Features**
- Detects common passwords (qwerty, 123456, etc.)
- Scores password on length, uppercase, lowercase, numbers, symbols
- Gives Weak / Medium / Strong result
- Suggests improvements

**Run**
```
python check.py
```

### 2. Caesar Cipher Tool (Python)
**File:** `caesar.py`

Encrypts and decrypts text using the Caesar cipher.

**Features**
- Encrypt with a chosen shift
- Decrypt with a known shift
- Brute-force mode that tries all 25 shifts without knowing the key

**Run**
```
python caesar.py
```

### 3. Password Strength Checker (Web)
**File:** `index.html`

Same password checker built with HTML, CSS and JavaScript. Gives live feedback as you type. Runs fully in the browser, no password is sent anywhere.

**Run:** Open `index.html` in any browser.
